两个版本的取舍：**首页和关于页放完整社徽**（能看到下方 MUN 横幅），**导航与页脚等小尺寸位置只放圆形部分**（横幅上的小字在小图标里会糊成一团）。

透明背景是用连通域算法从白底原图抠出来的：内部白色元素（橄榄枝、白字）完整保留，可直接放在深色背景上。

## 部署到 GitHub Pages

1. 新建公开仓库（如 `nymun`），勾选 Add a README
2. **上传 `site` 文件夹里面的内容**（`index.html`、`css/`、`js/`…），不要把 `site` 这个外层文件夹一起拖进去
3. Settings → Pages → Source 选 Deploy from a branch → Branch `main` / 文件夹 `/ (root)` → Save
4. 1—2 分钟后访问 `https://<用户名>.github.io/nymun/`

改内容：在仓库里直接编辑文件后 Commit，约 1 分钟自动生效，不用重新设置 Pages。

## 表单说明

报名意向表与章程意见表都是**真表单**：提交后通过 EmailJS 发送到社团收件邮箱（在 `js/main.js` 的 `TO_EMAIL` 里配置），正文为规整的「字段：值」格式，并附一行 CSV 便于整理进在线表格。

发件服务用 EmailJS 授权的邮箱账号（Gmail 最省事），收件邮箱可填任意地址（如 163）。

**代码已就绪，只差三个 ID**：打开 `js/main.js`，把顶部的 `PUBLIC_KEY` / `SERVICE_ID` / `TEMPLATE_ID` 换成 EmailJS 后台的值即可。完整图文步骤见 **[表单后端配置.md](表单后端配置.md)**。

提交失败时（如断网）内容会保存在填表人本机，页面提示直接发邮件，数据不丢失。

免费额度 200 封/月，招新规模够用。

## 设计与技术要点

- 配色：深海军蓝 `#07101f` + UN 蓝 `#2f6feb` + 金 `#e3c07a`（社徽主色取自原图 `#01407E`，与之呼应）
- 标题 Cormorant Garamond + Noto Serif SC 衬线，正文 Inter + Noto Sans SC
- 响应式断点：920px（Hero 单列）、860px（导航抽屉）、760px（结构图纵向）、720px（网格降列）、560px（表单单列）
- 支持 `prefers-reduced-motion`；中文字体走 Google Fonts CDN，国内加载慢可自托管

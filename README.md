# 南洋模联 NYMUN · 社团网站

上海市南洋中学模拟联合国社团官方网站。

## 关于本站

本站为南洋模联社**试运行阶段的社团网站**，目前处于建设与完善过程中，内容、结构与呈现方式都可能在后续调整。

**本网站仅用于社团内部使用**，不作为对外正式发布材料。

社团规模有限、人手紧张，网站中难免存在疏漏、错漏或表述不当之处。**欢迎各位提出宝贵修改意见**——无论是指出某处史实有误、某段文字不妥，还是对页面结构、内容编排有任何建议，我们都真诚欢迎。意见可通过网站「社团章程」页的意见征集表单提交，或直接邮件联系社团。

网站的每一次改动，都是为了让它更贴近社团的真实状况。

## 访问统计

站点挂了 Cloudflare Workers 后端统计 PV，接口地址写在 `js/main.js` 的 `STATS_ENDPOINT`。查看页面为 `stats.html`（不在导航中出现，在任意页面键入 `stats` 五个字母可进入，需输入查看密钥）。

**已知限制**：`workers.dev` 域名在国内直连不通，国内访客的上报请求会失败，数据长期接近 0，需开代理才能看到。若将来需要准确数据，可改用国内云函数（腾讯云 / 阿里云函数计算）。

## 部署

GitHub Pages：把 `site` 文件夹**里面的内容**上传到仓库根目录（不要把 `site` 外层文件夹一起拖进去），Settings → Pages → Source 选 `main` / `/ (root)`，1—2 分钟生效。

改内容：在仓库里直接编辑文件后 Commit，约 1 分钟自动生效。

本地预览：

```bash
cd site
python3 -m http.server 8000
```

## 设计与技术要点

- 配色：深海军蓝 `#07101f` + UN 蓝 `#2f6feb` + 金 `#e3c07a`
- 标题 Cormorant Garamond + Noto Serif SC 衬线，正文 Inter + Noto Sans SC
- 响应式断点：920 / 860 / 760 / 720 / 560px，手机端统一降列、三列卡片改横滑
- 支持 `prefers-reduced-motion`；中文字体走 Google Fonts CDN，国内加载慢可自托管
